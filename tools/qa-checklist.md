# QA 회귀 체크리스트

UI·데이터를 바꾼 뒤(특히 i18n·필터·모달 변경) **push 전에** 아래를 확인한다. 자동 스모크는
JS 에러만 잡으므로, 레이아웃·번역 누락·데이터 정합성은 여기서 함께 본다.

## 자동 (필수 통과)
- [ ] `node tools/build.js` — errors/computeMismatch/anchorFails/duplicates 모두 빈 배열, `bands.notInData` 빈 배열
  (errors에는 **카테고리 라벨 무결성**(모든 `cat`이 CAT_ORDER·CAT_NAMES에 존재)과
  **subAgency 배치**(K-idol `기타`에만) 검증도 포함된다)
- [ ] `node tools/ops-metrics.js --check` — 에러 없이 실행(파이프라인 지표 툴 무결성)
- [ ] 헤드리스 스모크 — 페이지 로드 + 계산 실행 시 **JS 에러 0**, `IDOLS.length > 0`
- [ ] 정합성 — `idols.json` 수 == `stats.json.total` == 빌드본 `IDOLS` 길이, `name|group` 중복 0

## 코어 플로우
- [ ] 생년월일 8자리 입력 → 계산 → 순위 카드 표시(1~8위), 전체 펼치기 동작
- [ ] 시각·성별 선택 시 순위 변동(미선택 시 중립), 결과 라벨 정상
- [ ] 공유: 이미지 생성 + 캡션(해시태그·링크) 정상
- [ ] 사용 비콘: 각 콘텐츠(match/pair/profile/tri/share/suggest) 진입 시 `/beacon`에
      `{"e":...}`만 전송(개인정보 없음), 하루 1회 중복 제거, DNT=1이면 미전송, JS 에러 0

## 필터 (각각 동작 + 서로 충돌 없음)
- [ ] 카테고리(노출 시)·검색·소속사·하위 그룹·성별 탭·🎸밴드 토글 각각 필터링 정상
- [ ] 필터 조합 후에도 빈 화면/깨짐 없음. 밴드 토글은 범위에 밴드 있을 때만 노출

## 모바일(폭 ~390px)
- [ ] 텍스트 오버플로/어색한 줄바꿈 없음(CJK `keep-all`, 고유어구 `.nowrap`)
- [ ] 버튼·배지·카드가 넘치거나 잘리지 않음(특히 CTA·성별·소속사·밴드 버튼)
- [ ] 팝업(업데이트 공지·주간 최애 리포트·제보·오류 모달) 열림/닫힘, 서로 겹치지 않음

## 다국어(i18n 변경 시)
- [ ] **KO 기본 화면이 그대로 정상**(폴백) — 번역 미완 문자열도 KO로 표시, 화면 안 깨짐
- [ ] 언어 전환(KO/EN) 시 남은 미번역은 KO로 폴백(빈 문자열/`undefined` 금지)
- [ ] EN에서 긴 문장으로 버튼·배지 오버플로 없음

## 데이터/제보 위생
- [ ] 테스트·장난 제보 제외: 이름/그룹이 비었거나 `-` 등 무의미, 명백한 테스트(예: `배우`,
      `솔로` 단독, 실존 확인 불가)는 idols.json에 반영하지 않음
- [ ] 반영/오신고 처리한 제보 key는 `inbox-done.json`에 기록

> 하나라도 실패하면 **push 금지**, 무엇이 깨졌는지 기록.
