지금 UI를 건드리면 근거 없는 수정이 된다.

### 🎨 디자이너 (3년차) — UX·사용자 친화성
**진입 동선은 구조적으로 문제없다.** 5개 모드가 `mode-grid`에서 동일 위계의 카드로 제시되고,
신규 오타쿠는 `mode-otaku` 하이라이트 클래스로 시각 강조되어 있다(`index.html:557-559`).
"무엇을 볼까요?" 헤드 아래 카드 5장 — 첫 진입 마찰 낮음.

**모바일 390px 실측(스모크).** 카드 그리드 5장 · 순위 8장 · 전체 366행 · 4개 언어 전환 —
**가로 오버플로 0건**. 언어 전환 후에도 유지. 레이아웃 회귀 없음.

**사용 저조 콘텐츠의 동선·설명 점검은 이번 주 보류.** 루틴상 `contentUsage`로 저조 항목의
진입 동선·설명 부족을 점검해야 하지만, ① 저조로 지목된 삼각관계·제보는 표본 9명 중 0이라
동선 문제인지 표본 문제인지 구분이 안 되고, ② 오타쿠는 데이터가 아예 없다.
**근거 없이 동선을 고치면 개선이 아니라 변경일 뿐** — P7 해소 후로 미룬다.

**관찰 1건(수정 완료).** README 노출 카테고리에 "K-actor"만 영문으로 섞여 있었다.
사용자 대면 문구의 언어 일관성 문제라 §2에서 정정했다.

### 👔 팀장 (8년차) — 종합·판정

**동의된 것.** 데이터 건강(정합성 100%·중복 0·백로그 -37%·i18n 100%)은 4개 팀 모두 이견 없음.
K-actor 개방이 코드 변경 없이 데이터만으로 이뤄진 것도 설계가 의도대로 작동한 사례로 평가한다.

**충돌 없음, 그러나 세 팀이 같은 벽에 부딪혔다.** 기획자는 신규 모드 성과를 못 보고, 디자이너는
저조 콘텐츠 동선을 못 고치고, 개발자는 커밋이 오염된다고 한다. **셋 다 원인이 하나 — 구버전 워커다.**

**판정 1 (최우선). 워커 재배포 1회를 요청한다.**
P6(무변경 커밋 차단, 코드 3줄)과 P7(오타쿠 계측)은 **분리 처리하지 않는다.** 어차피 재배포가
필요하고, 한 번의 배포로 하루 144건 커밋 낭비와 신규 모드 미계측이 동시에 사라진다.
이번 주 승인 요청은 **사실상 이것 하나**다.

**판정 2. 동일 인물 중복 23건은 자동 수정하지 않는다 — 정책 결정 사안이다.**
QA가 사실을 확증했지만(김세정 = 아이오아이 = 구구단), 프로젝트 그룹 데이터를 지우는 것은
"그룹 다양성"이라는 자산을 깎는 일이라 리뷰가 단독으로 판단할 사안이 아니다.
**팀장 권고: (c) 데이터는 그대로 두고, 순위 산출 시 동일인은 1회만 노출한다.**
근거 — 그룹 탐색·필터용 데이터 자산은 보존하면서 사용자 눈에 보이는 중복만 제거하는,
유일하게 잃는 것이 없는 선택지다. 상세·대안은 P8.

**판정 3. P2(소속사 Phase 2)는 재촉하지 않고 대기 유지한다.**
promotable이 4개 → **5개**(스윙엔터테인먼트 31 신규), 커버리지 79% → 88%로 조건은 더 무르익었다.
다만 지난주 재문의에 아직 응답이 없어 **같은 질문을 반복하지 않는다.** 결정 요청 목록에만 다시 올린다.

**판정 4. 이번 주 코드·데이터 자동 수정은 최소로 유지했다.**
`idols.json` 수정 0건, 확증된 툴 라벨 결함 1건만 수정. QA가 찾은 `window._saju` 미가드는
**사용자 도달 불가를 확인했으므로 고치지 않고 P9로 남긴다** — 영향 없는 코드를 승인 없이
건드리지 않는다는 안전규칙 그대로다.

## 5. 신규 데이터·기능 아이디어

- **오타쿠 사주 → 코어 회귀 동선.** 오타쿠 결과 하단에 "같은 덕질 유형인 아이돌 TOP3"를 붙여
  파생 모드에서 코어(사주궁합)로 되돌린다. 계산 로직은 이미 있는 것을 재사용 — 단, **P7로 오타쿠
  실사용을 확인한 뒤**에 판단할 일이다.
- **완주율 계측.** 현재 비콘은 "진입"만 센다. 결과 도달 시점 이벤트를 1개 추가하면
  *진입 대비 완주율*이 보여 "저조"가 동선 문제인지 이탈 문제인지 구분된다.
  단 KV 쓰기 예산(순사용자 1명당 최대 6→7쓰기/일)을 먼저 계산해야 한다.
- **K-actor 축을 살린 문구.** 배우 31명이 노출되기 시작했으니 "드라마 최애"라는 진입 문구가
  성립한다. 데이터는 이미 있고 문구만 추가하면 되는 저비용 확장.
