# 개선 제안 백로그 (상세 실행안)

주간 운영 리뷰(§4)가 낸 제안을 **실행 가능한 스펙**으로 구체화한 살아있는 문서.
각 제안은 아래 필드를 반드시 채운다: 배경 · 목표(측정가능) · 구체 변경안(파일·방식) ·
단계/공수 · 예상효과 · 리스크 · **결정 필요** · 상태.

> 상태 표기: `제안`(승인 대기) → `승인` → `진행` → `완료`. 큰 변경은 사용자 승인 전
> 코드/데이터에 반영하지 않는다(OPS_ROUTINES 안전규칙).
